# HR Analytics Dashboard 📊

## 📌 Project Overview
This project is an HR Analytics dashboard built using Power BI. It helps organizations analyze employee data and gain insights into attrition, performance, and workforce trends.

## 🎯 Objectives
- Analyze employee attrition
- Understand workforce demographics
- Identify key factors affecting employee retention

## 🛠 Tools Used
- Power BI
- Excel (for dataset)

## 📊 Key Insights
- Attrition rate by department
- Age group analysis
- Salary vs attrition trends
- Job satisfaction levels
